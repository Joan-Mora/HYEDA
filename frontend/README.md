# HYEDA Frontend

SPA React + Vite para el patio de Herramientas y Equipos del Ariari.

```bash
npm install
npm run dev
```

- App: http://localhost:5173
- API: `http://localhost:8081/api`
- Login: `admin` / `AdminHyeda2026!`

Design system propio (tokens navy/accent), React Hook Form + Zod, guards por permiso.
